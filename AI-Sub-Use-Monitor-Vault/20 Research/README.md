## Dates

Every note has YAML frontmatter:

- `researched` — date of the last full pass (`YYYY-MM-DD`). Empty means we have not researched it yet.
- `updated` — date of the last edit, even a small one.
- `status` — `empty` | `researched`

When you learn something, write it in that platform's note and bump `updated`. When you redo the pass from scratch, bump `researched` too. Do not guess endpoints into an empty note.
